# 🎬Movie Explorer

A modern and responsive Movie Explorer web application built with React and Tailwind CSS. Users can browse movies/shows, search for specific titles, and view detailed information through an interactive movie card modal.

The project uses the TVMaze API to fetch and search movie/show data.

---

## Live Demo

🔗 Live Demo: https://movie-explorer-seven-neon.vercel.app/

---

## ✨ Features

- 🎬 Browse all available movies and TV shows
- 🔍 Search movies functionality
- 📱 Fully responsive design
- 📱 Responsive for all devices
